# Icon provenance

These are the unchanged default development icons that `tauri init` writes, taken from
`@tauri-apps/cli` 2.12.5 (`tauri-cli 2.12.5`, npm registry, modified 2026-11-16). They are
placeholders until final branding exists and must not be read as OAH branding.

- How they were obtained: `tauri init --ci` ran in a private scratch folder outside the product
  directory, and only the five files that `tauri.conf.json` declares under `bundle.icon` were copied here.
- Source license: the Tauri CLI is `Apache-2.0 OR MIT`; the Tauri logo remains a Tauri trademark.
- No file was edited, recolored, resized or regenerated.
