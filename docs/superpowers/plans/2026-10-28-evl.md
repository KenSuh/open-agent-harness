# Lane evl: Real-Case Evaluation Runner Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan
> task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `oah eval` replays real cases reproducibly. A case is the code before a fix plus the
requirement at that time. The expected answers (the oracle) stay hidden from every agent. Two or more
variants run from the same starting state. The report gives honest metrics, marks unknowns as
`unknown`, and never claims that one variant is better.

**Architecture:**
- **Package `oah.eval`:** `errors` (codes), `case` (case folder and digest), `plan` (plan TOML,
  preregistration), `workspace` (fresh repository and isolation scan), `runner` (variants), `grade`
  (oracle match rules, human verdicts) and `report` (aggregates and limits). The modules take no
  configuration; settings arrive as parameters with module-level `DEFAULTS`.
- **Command module `oah/eval_cli.py`:** `oah eval prereg|run|grade|report`, found by command
  discovery. It reads `[eval]` from `.oah/config.toml` when it runs inside a repository.
- **Run folders:** `<state dir>/eval/runs/<run id>/` (`oah.paths.state_dir`, or `OAH_STATE_DIR`).
  Every JSON is written with `oah.atomic`.
- **Workspaces:** each variant gets its own fresh temporary folder `oah-eval-*/` with `repo/`, `inputs/`,
  the requirement copy and an empty `output/`. After the variant ends, `repo/` and `output/` are copied
  into the run folder and the temporary folder is removed.

**Tech Stack:** Python 3.11+ stdlib (`tomllib`, `hashlib`, `tarfile`, `zipfile`, `unittest`), git
through `oah.paths.git_argv` and `oah.engines.proc.run_command`.

**Spec:** the lane brief's intent `evl` r1 (AC1–AC7); `docs/PLAN.md` 3, 5.3, 5.9, 8.

## Global Constraints

- Standard library only. Never use `shell=True`; the task prompt goes on stdin. Every read and write
  states UTF-8, and the TOML parsers accept CRLF. Executables are resolved through
  `oah.engines.proc`, and `.cmd`/`.bat` files are never launched.
- Each new `.py` file starts with a one-line Korean comment naming its role.
- Exit codes: 0 ok, 1 refused (all `OAH_EVAL_*` refusals), 2 usage (argparse), 69 environment
  (git missing, unreadable state, a variant command that is not installed).
- **Messages:** every message starts with its code and says what to do next.
- **Fixtures:** synthetic only. The fixture bundle is rebuilt by a committed script with a fixed identity
  and fixed dates, so its commit ids are reproducible.
- **No models in tests:** the fixture variants are fake engines and are labelled
  `control-flow-only`.

## Formats

**Case folder** (`case.toml` plus `inputs/`):
```toml
id = "derived-index"
split = "dev"                      # dev | control | holdout
provenance = "Synthetic case ..."
requirement = "requirement.md"     # relative to the case folder
prompt = "task.md"                 # variant-independent task prompt, sent on stdin
forbidden = ["*.orig"]             # optional fnmatch patterns; refused when present in the workspace

[snapshot]
file = "snapshot.bundle"
format = "bundle"                  # bundle | tar | zip
commit = "<40 hex>"
```
Every named path must stay inside the case folder. The oracle is never inside the case folder.

**Oracle** (TOML, path given only to `prereg` for hashing and to `grade`):
```toml
case = "derived-index"
[[defect]]
id = "D1"
files = ["index.txt"]     # a finding must name one of these files ...
keywords = ["stale"]      # ... and contain every keyword (case-insensitive); at least one of the two lists
[[test]]
id = "T1"
command = ["{python}", "check_index.py"]   # must fail on the snapshot; passing after the variant = fixed
timeout_seconds = 60
```

**Plan** (TOML):
```toml
[[case]]
path = "cases/derived-index"     # relative to the plan file
used_for_development = false

[[variant]]
name = "baseline"
command = ["{python}", "{plan_dir}/variants/fake_variant.py", "miss"]
fake = true                      # control-flow-only
timeout_seconds = 120            # optional
config = "configs/x.toml"        # optional oah configuration, written to repo/.oah/config.toml
```

**Variant contract:** cwd is `repo/`. Environment adds `OAH_EVAL_INPUTS`, `OAH_EVAL_REQUIREMENT` and
`OAH_EVAL_OUTPUT`. The variant may write `$OAH_EVAL_OUTPUT/result.json`:
`{"findings": [{"id", "file" | "files", "title", "summary", "detail"}], "usage": {...},
"rounds": int, "corrections": int, "engine": "fake"}`. Anything missing is `unknown`.

**Preregistration:** `oah eval prereg PLAN --oracle FILE... --out FILE` writes the frozen JSON
(`format`, cases with id/split/path/`case_sha256`/snapshot commit/`used_for_development`/`oracle_sha256`,
variants with the exact command, file digests of command arguments, embedded config text, fixed metrics
and grader rules) and `FILE.sha256`.

## Review Focus

- The isolation scan runs on every workspace before **any** variant launches, and the refusal names what it
  found.
- History objects are all bundle objects minus the snapshot tree's own trees and blobs; a workspace with
  any of them (or with alternates) is refused.
- Holdout rules: refused without a matching preregistration, and refused when the preregistration says the
  case was used for development.
- Grading never labels an unmatched finding a false positive; only a human verdict file can.
- The report prints its limits and no superiority claim.

### C1 design decisions and user-visible changes

- F1 (`workspace.py`): validate the full tar/zip member list before writing any member; users receive
  `OAH_EVAL_SNAPSHOT` for filesystem-equivalent Git metadata names, including Windows aliases.
- F2 (`workspace.py`): discard all ambient `GIT_*` variables, then apply only the explicit fixed
  identity; construction and scanning cannot operate on a caller-selected repository or trace file.
- F3 (`workspace.py`, `runner.py`): retain decoded UTF-8 prompt text once, scan its exact encoded stdin
  bytes and filename, and launch that same text; oracle copies in prompts are refused, including BOM/CRLF copies.
- F4 (`workspace.py`): preserve copied input links, check forbidden names before following anything,
  and inspect committed 120000 targets independently of checkout representation; users must replace
  escaping/directory links and linked case input roots, while safe internal file links still work.
  Reject input directory links/reparse points before copying because Python 3.11 follows Windows
  junctions even with `copytree(symlinks=True)`.
- F5 (`runner.py`): union every preregistered oracle's comparison hashes; a case cannot carry another
  case's answers into a variant.
- F6 (`runner.py`, fake variant fixture): allow only the documented runtime environment plus three
  workspace variables; caller oracle paths and arbitrary metadata disappear from variant environments.
  Test marker, record folder and exit settings use explicit fake-command flags, with no runtime exemption.
- F7 (`workspace.py`): refuse embedded metadata and recognizable bundle/pack/loose-object containers
  rather than opening nested repositories; users must supply source material without embedded history.
  Loose-object header decompression is bounded. This remains a contents scan, not a sandbox.
- F8 (`report.py`): aggregate each usage key independently, always considering input/output tokens and
  cost; users see unknown partial or absent fields in both totals and limits, while recorded zero is valid.
- F9 (`grade.py`): refuse duplicate normalized IDs with `OAH_EVAL_FINDING_DUPLICATE` before any matching
  or verdict application; users must provide unique IDs instead of losing unmatched findings.
