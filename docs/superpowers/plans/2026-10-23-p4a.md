# P4a Packets, Intent and Preflight Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agents keep the original goal between stages and do not start on a stale or contested base.
The commands are `oah packet new/check`, `oah intent show/check` and `oah preflight`. The intent
section, its digest, the four binding states, the return checks and the shared footer live in one
module, `oah.intent`, that later lanes reuse.

**Architecture:**
- `oah.intent` is pure: it parses text, computes the digest, reads a source file safely and answers
  questions about a binding. It knows nothing about leases, packets or config.
- `oah.packet` owns the packet file: the template, the task folder, the section checks, the scope
  list and a structural check of an optional `GATES.md`.
- `oah.preflight` runs the 5.7 checks and returns a report. Settings, the impact step and the project
  checks are parameters, so lane P4b can inject `oah.impact.ensure_fresh` and the configured checks.
- The three `*_cli.py` modules follow `lease_cli.py`: `register(subparsers)`, `COMMANDS` and
  `run(args) -> int`. They never touch `src/oah/cli.py`; command discovery comes from lane P3a.

**Tech Stack:** Python 3.11+ stdlib (`hashlib`, `re`, `os.lstat`/`os.fstat`, `importlib.resources`,
`unittest`), git through `oah.paths.run_git` and `oah.engines.proc`.

**Spec:** `docs/PLAN.md` 5.6, 5.7, section 4 rows 12–14, section 15 (P4 checklist items A2, A4, A7;
candidate C1), plus the lane intent `p4a@r1`.

## Global Constraints

- Everything from the P1 and P2 plans' Global Constraints still applies: stdlib only, never
  `shell=True`, UTF-8 on every read and write, a Korean one-line header on new `.py` files, test
  writes inside the checkout (`TMPDIR=$PWD/.tmp/test-tmp`).
- **Exit codes:** 0 ok, 1 refused, 2 usage, 69 environment. Preflight uses 0 for PROCEED and
  PROCEED_WITH_WARNINGS and 2 for ABORT, as 5.7 says.
- **Messages** start with an `OAH_*` code and say what to do next.
- **Markers.** `<!-- OAH_INTENT:BEGIN -->` and `<!-- OAH_INTENT:END -->`, each exactly a whole line
  at line start (after CRLF→LF). A line that starts with `<!--` and mentions
  `OAH_INTENT:BEGIN` or `OAH_INTENT:END` without being the exact marker is malformed.
- **Section layout** (between the markers, in this order): `## Intent`; the fields `Intent-ID`,
  `Revision` and `Status`, once each; then `### Problem`, `### Desired outcome`,
  `### Success conditions`, `### Constraints`, `### Non-goals` and `### Open questions`, once each.
  A field value may carry a trailing `# comment`, as the template does.
  - `Intent-ID` matches the lease task pattern. `Revision` is a positive integer without leading
    zeros. `Status` is `draft` or `accepted`.
  - Success conditions are top-level bullets `- AC<n>: <text>` with unique ids and non-empty text,
    at least one. Indented lines continue the bullet above. Any other top-level bullet is invalid.
- **Digest.** `sha256:` + the hex sha256 of the UTF-8 bytes from the start of the BEGIN line to the
  end of the END marker, after CRLF→LF (and lone CR→LF), plus exactly one LF.
- **Source files** must be regular files, not symlinks, under 1 MiB (`size < 1048576`), and
  unchanged between `lstat` and the read: same device, inode, size and mtime, read length equal to
  the size. They decode as UTF-8; a leading BOM is ignored.
- **Binding.** `Binding(source, id, revision, digest, acs)`. `source` resolves against the
  repository root when relative. JSON form: `{"source", "id", "revision", "digest", "acs"}`.
  `acs` is part of the binding so that the return check needs no file access.
- **Binding states**, first match wins: `unbound` (no binding), `missing` (the source path does not
  exist, not even as a dangling link), `current` (readable, well-formed, accepted, and the ID,
  revision, digest and AC ids equal the binding's), `stale` (everything else).
- **Return lines.** `INTENT <id>@r<n> sha256:<hex>` and `AC<n>: met|unmet|deferred — <evidence>`.
  ` -- ` is accepted in place of ` — ` for keyboards without an em dash. A line whose stripped
  text starts with `INTENT` or with `AC<n>` followed by a colon is a candidate; a candidate that does
  not match exactly is malformed. Other lines are free text.
- **Footer.** `FOOTER` starts with the marker line `<!-- OAH_INTENT_FOOTER -->`. `has_footer`
  counts it only when that marker is a whole line at line start (C4).
- **Packets** live at `.oah/tasks/<task>/PACKET.md`; `packet new` never overwrites.

## Review Focus

1. **A CRLF copy of a packet** has the same digest as the LF copy. →
   `test_digest_equal_for_crlf_and_lf`.
2. **Invalid content can never be `current`**: duplicate, malformed and missing markers, bad fields,
   a draft, a changed identity or digest, a symlink, an oversized file and a file swapped during the
   read. → `test_binding_state_table`, `test_read_source_refuses_change_between_stat_and_read`.
3. **A return that only looks right**: a duplicated AC line, an invented AC, an INTENT line with the
   right ID but another digest, two INTENT lines. → `test_check_return_table`.
4. **Preflight on a stale base** aborts with the rebase command, and an unreachable remote aborts
   unless `--offline`. → `test_behind_remote_aborts_with_rebase_command`,
   `test_unreachable_remote_aborts_unless_offline`.
5. **A footer that is only mentioned** in a sentence is not counted as present. →
   `test_has_footer_requires_marker_line`.

### Task 5: `oah preflight`

**Files:**
- Create: `src/oah/preflight.py`, `src/oah/preflight_cli.py`, `tests/test_preflight.py`

**Interfaces:**
- Produces:
  - `DEFAULTS = {"remote": "", "default_branch": "", "fetch_timeout": 60.0, "check_timeout": 300.0}`.
    Empty `remote` means `origin`, or the only remote; empty `default_branch` means the remote's HEAD.
  - `Check(name, level, message, details)`; levels `ok`, `info`, `warn`, `abort`.
  - `Report(checks, impact, not_proven)` with `.verdict`, `.exit_code`, `.render()`.
  - `ImpactHook = Callable[[Path, tuple[str, ...]], Sequence[str]]`: given the root and the
    normalized `--touch` paths, it returns information lines (the bound gates).
  - `run_checks(info, *, state, task=None, touch=(), offline=False, settings=None, impact=None,
    project_checks=()) -> Report`. `state` is the lease state folder (`oah.paths.state_dir`).
  - `preflight_cli`: `COMMANDS = ("preflight",)`; `oah preflight [--task T] [--touch PATH…] [--offline]`.
- Checks, in order: `base`, `dirty`, `leases`, `recent`, `impact`, `packet`, `project`.
  - The comparison scope is the union of `--touch`, the packet Scope and the task's own lease scope.
    An empty comparison scope is a WARN and never silently passes (A4).
  - Fetch runs with `GIT_TERMINAL_PROMPT=0` so it never waits for a password.
  - The packet's base for `recent` is the task lease's `head_at_start`, else the last commit that
    changed the packet, else the packet's modification time. Without a base the check is skipped.
  - `impact=None` prints `impact=unavailable` and adds the impact item to the not-proven list.
- [ ] **Step 1: Failing tests** (temporary bare remote, real git): `test_up_to_date_clean_proceeds`,
  `test_behind_remote_aborts_with_rebase_command`, `test_unreachable_remote_aborts_unless_offline`,
  `test_no_remote_warns`, `test_dirty_tree_warns`, `test_overlapping_lease_aborts_and_stale_warns`,
  `test_empty_compare_scope_warns`, `test_recent_commits_touching_scope_warn`,
