# P1 Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A packaged `oah` CLI with `--version` and `doctor`, the Windows-safe process layer it runs
on, this repository's privacy scan, and the macOS + Windows CI that tests all of it.

**Architecture:** Standard-library Python under `src/oah/`. `engines/proc.py` is the only place that
resolves and runs external programs, and every later phase reuses it. `doctor.py` is a pure function
over an injected resolver and runner, so the tests never touch the machine's real tools. The privacy
scan is a standalone `tools/` script, not part of the package.

**Tech Stack:** Python 3.11+ stdlib (`argparse`, `subprocess`, `tomllib`, `unittest`), setuptools
build backend, GitHub Actions.

**Spec:** `docs/PLAN.md` (sections 3, 5.2, 5.3, 5.13, 6.1, 6.3, 8, 10, 11)

## Global Constraints

- Python `>=3.11`, standard library only at runtime and in tests.
- Distribution `open-agent-harness`, console script `oah = "oah.cli:main"`, version `0.1.0.dev0`.
- `LICENSE` is MIT with the line `Copyright (c) 2026 open-agent-harness contributors`.
- Never `shell=True`. Never launch `.cmd` or `.bat` directly. A recognized npm shim runs as
  `node.exe <package bin script>`. Anything else is refused with `OAH_UNSUPPORTED_BATCH_SHIM`.
- Capture subprocess stdout/stderr as bytes and decode with an explicit encoding (UTF-8 default)
  and `errors="replace"`.
- Before printing, `oah`'s stdout/stderr keep their encoding with `errors="backslashreplace"`.
- Every file read and write passes `encoding="utf-8"`.
- `oah` output is ASCII-only in P1.
- New `.py` files start with a one-line Korean comment naming the file's role (after any shebang).
- No personal data in tracked files or commits. Run `tools/privacy_scan.py` before every push.
- **CI:**
  - triggers on `pull_request` to `main` and on `workflow_dispatch`, and skips `docs/**` and root
    `*.md`;
  - runs exactly one `macos-latest` and one `windows-latest` job, on Python `3.11`;
  - pins `actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1` (v7.0.1) and
    `actions/setup-python@5fda3b95a4ea91299a34e894583c3862153e4b97` (v7.0.0);
  - sets `permissions: contents: read`, cancels superseded runs, and times out after 15 minutes.
- Local runs keep every write inside the checkout:
  `TMPDIR="$PWD/.tmp/test-tmp" python3.11 -m unittest discover -s tests -t . -v`.

## Review Focus

1. A tool installed only through an npm `.cmd` shim on Windows (the usual npm install of codex):
   doctor must report its version through `node.exe` + the bin script → Task 3
   `test_windows_npm_shim_keeps_metacharacters_literal`, Task 5 `test_npm_shim_tool_reports_version`.
2. Spaces, `& ^ % ! ( )` and Korean in the tool's folder, and `& | < > ^ % ! ( )` in arguments: argv
   stays literal and nothing is injected → Task 3 Windows test above, plus
   `test_posix_executable_runs_directly` for POSIX.
3. A tool that hangs or leaves children behind: the timeout returns promptly and the whole tree dies
   → Task 3 `test_timeout_kills_process_tree`, Task 5 `test_timeout_is_reported_not_fatal`.
4. Redirected cp949 stdout/stderr with Korean, emoji and malformed subprocess bytes: no
   `UnicodeEncodeError` → Task 2 `test_cp949_stream_survives_emoji_and_replacement_char`, Task 5
   `test_cli_under_cp949_io_encoding`.
5. Version text on stderr, behind ANSI escapes, or with an empty stdout: the first meaningful line is
   reported → Task 5 `test_version_from_stderr_with_ansi`.

### Task 3: Resolving and running external commands

**Files:**
- Create: `src/oah/engines/__init__.py`, `src/oah/engines/proc.py`, `tests/test_proc.py`,
  `tests/helpers.py` (temp-dir and fake-tool helpers shared by later tests)

**Interfaces:**
- Produces:
  - `class UnsupportedBatchShim(Exception)`: has `code = "OAH_UNSUPPORTED_BATCH_SHIM"` and `path: str`.
    The message tells the user to install the native executable or configure an explicit
    `[interpreter, script]` command.
  - `@dataclass(frozen=True) class Resolved`: `argv: tuple[str, ...]`, `source: str`, and `kind`,
    which is `"native"` or `"npm-shim"`.
  - `resolve_command(name: str, search_path: str | None = None) -> Resolved | None`: runs
    `shutil.which` and then `classify`.
  - `classify(found: Path, name: str, *, platform: str, search_path: str | None) -> Resolved`:
    - On `win32`, a `.cmd`/`.bat` file goes through npm resolution.
    - npm resolution looks for the package whose `package.json` `bin` maps `name`. It searches
      `found.parent/node_modules/<pkg>` and `node_modules/@scope/<pkg>`; a string `bin` maps the
      unscoped package name.
    - Exactly one match, or the refusal is raised.
    - The interpreter is `found.parent/"node.exe"` if present, otherwise `node.exe` from `search_path`.
  - `@dataclass(frozen=True) class RunResult`: `returncode: int | None`, `stdout: str`, `stderr: str`,
    `timed_out: bool`.
  - `run_command(argv: Sequence[str], *, timeout: float, cwd: str | None = None, env: Mapping[str, str] | None = None, encoding: str = "utf-8", stdin_text: str | None = None) -> RunResult`:
    - It refuses an `argv[0]` ending in `.cmd`/`.bat` in any letter case, as defence in depth.
    - On POSIX it starts a new session. On Windows it uses `CREATE_NEW_PROCESS_GROUP`.
    - On timeout it calls `kill_tree` and still collects the output.
  - `kill_tree(proc: subprocess.Popen) -> None`:
    - POSIX: `os.killpg(proc.pid, SIGKILL)`.
    - Windows: `%SystemRoot%\System32\taskkill.exe /T /F /PID <pid>`, falling back to `proc.kill()`.
  - `decode_output(data: bytes, encoding: str = "utf-8") -> str`: uses `errors="replace"`.

### Task 6: Privacy scan for this repository

**Files:**
- Create: `tools/privacy_scan.py`, `tests/test_privacy_scan.py`

**Interfaces:**
- Produces:
  - `Term(kind: "word" | "substr", text: str)` and `load_terms(path: Path) -> list[Term]`. The format is
    one `word <t>` or `substr <t>` per line, with `#` comments. Matching is case-insensitive.
  - `scan(repo: Path, terms: list[Term], gitleaks: str) -> Report`, where `gitleaks` is `auto`,
    `require` or `off`.
  - `main(argv: list[str] | None = None) -> int`:
    - flags `--repo`, `--terms`, and `--gitleaks`;
    - `--terms` defaults to `.oah-dev/privacy-terms.txt` when it exists, with a warning when it does not.
- Rules:
  - home paths `/Users/<x>`, `/home/<x>` and `<drive>:\Users\<x>`, with `<...>` placeholders allowed;
  - email addresses, allowing `*@users.noreply.github.com`, `noreply@github.com`, `noreply@anthropic.com`
    and `example.com`/`.org`/`.net`;
  - key shapes:
    - `sk-` followed by 20 or more characters, with no letter or digit before it;
    - `gh[pousr]_` followed by 36 characters;
    - `github_pat_` followed by 22 or more characters;
    - `xox[abprs]-…`;
    - `AKIA` followed by 16 characters;
    - a `PRIVATE KEY` header;
  - uppercase env assignments of `…KEY|TOKEN|SECRET|PASSWORD` with a value of 12 or more characters;
  - keychain commands;
  - the local terms.
- Scope:
  - HEAD tree file contents;
  - added lines across `git log -p`;
  - commit messages;
  - author and committer emails, which must be allowlisted.
- Output:
  - `path:line: <rule>` with the matched value redacted;
  - a final line `PRIVACY_SCAN_CLEAN files=<n> commits=<m> gitleaks=<ran|skipped>` (exit 0) or
    `PRIVACY_SCAN_HITS n=<k>` (exit 1);
  - exit 2 on usage or environment errors.
- The script's own pattern sources are built from fragments, so neither it nor a plain `git grep` of
  the brief's words flags it. The tests build secret-shaped strings at runtime for the same reason.
