# P9 Beginner Docs, Worked Example and Troubleshooting Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A newcomer reads the README, installs `oah`, runs `oah init` and follows `examples/hello-oah`
through the whole loop. Concepts, troubleshooting, upgrade and keys each have one page in English and
Korean, and two tests keep the docs from drifting away from the code.

**Architecture:**
- **Docs:** `README.md` (English, with a Korean section of the same structure), `docs/<page>.md` and
  `docs/ko/<page>.md` for concepts, troubleshooting, upgrade and keys. Existing install, CI starter and
  companion pages get only stale-status fixes.
- **Example:** `examples/hello-oah/` holds a tiny Python program, its tests and two READMEs
  (`README.md`, `README.ko.md`) that walk the loop with real commands.
- **Tests:** `tests/test_docs.py` checks the docs against `src/oah/`; `tests/test_example_hello.py` runs the
  walkthrough's `oah` commands with fake engines.

**Tech Stack:** Python 3.11+ stdlib (`unittest`, `re`, `shlex`), the existing fakes in `tests/fakes/`
and the in-process CLI runner and stub `node` in `tests/fixtures/gates/support.py`.

**Spec:** `docs/PLAN.md` sections 3, 5.3, 6.5, 8, 9 and 15 (P9 checklists A9–A17, OB, A20, A21, C5;
the Release checklist).

## Global Constraints

- No code under `src/oah/` changes except the owner-authorized v0.1.0 version string in C2.
  Wrong behaviour found while writing is reported, not fixed.
- Every command shown in a doc was run, or read from its parser and tests, on `main` plus the P6b
  (`oah fix`) and P7b (`oah init`) branches. Statements about those two commands are rechecked after the
  coordinator rebases this lane.
- No key, token or account identifier appears anywhere; examples use `${NAME}` placeholders only.
- No personal paths, user names or machine details; the privacy scan stays clean.
- Korean sentences never end with a colon.
- No document claims a fixed effort cap (C5); effort text follows A1.
