# P4b Intent, Skills and Impact Wiring Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One task flows end to end. `oah packet new` plans the task, `oah start --packet` binds the
accepted intent, `oah status` and `oah intent show` report the binding, `oah call` refuses a stale
binding and delivers briefs with the selected skills and the intent footer, and `oah finish` checks
the return against the binding.

**Architecture:** This lane wires modules that already exist on `main`; it adds no new subsystem.
- `oah.intent` (P4a) parses, digests and judges bindings. The lease gains an optional `intent` field.
- `oah.skillsel` (P3s) selects skills, and `oah.rerank` (P3s) may re-order them.
- `oah.impact.ensure_fresh` (P7i) refreshes the map before `preflight` and `packet new`.
- `oah.briefs` and `oah.call` (P3b) carry the skills and the refusal.

**Tech Stack:** Python 3.11+ stdlib, `unittest`, temporary git repositories, the fake engines in
`tests/fakes`.

**Spec:** `docs/PLAN.md` 5.4 (lease record), 5.5 (axes and tiers), 5.6, 5.7, 5.10 (A11, A15), section 4
rows 12–14, section 15 (A7, A9, A10, A11, A15, A23, the P4 and P4b checklists, candidate C1).

## Global Constraints

- Everything from the earlier plans still applies: stdlib only, never `shell=True`, UTF-8 on every
  read and write, parsers accept CRLF, executables resolve through `oah.engines.proc`, and every new
  `.py` file starts with a one-line Korean comment.
- **Lease schema stays version 1.** `intent` is optional. A record without it loads as before. A
  record without a binding writes no `intent` key, so old files stay byte-compatible. A malformed
  `intent` is `OAH_STATE_CORRUPT`, never ignored.
- **The binding** is `oah.intent.Binding.to_json()`: `{source, id, revision, digest, acs}`. `source`
  is repository-relative with forward slashes, and its state is judged against the lease's worktree.
- **Re-ranking is consent-gated and never required.** `oah.rerank.rerank` runs a provider only when
  `[rerank] enabled = true`, a provider is named and its key exists. Every brief, run record and
  packet plan records `rerank=used` or `rerank=unused(<reason>)`. A re-ranked order must be a
  permutation of the rule order; anything else falls back to the rule order. The config is loaded from
  the target repository root, never the current directory.
- **`[skills]` is shared** by the selector (`mode`, `rules`, …) and the toolkit updater (`pins`,
  `update_interval_days`, …). Readers in this lane merge both default sets, so neither side's keys
  raise `OAH_CONFIG_UNKNOWN_KEY`.
- **Impact refresh.** `preflight` and `packet new` call `ensure_fresh(root)` first. Any failure except
  "no commits yet" refuses with `OAH_IMPACT_STALE`. A repository without commits reports
  `impact=unavailable(no commits yet)`, because there is nothing to map. Neither command fetches
  anything for impact.
- **Tests read nothing from this machine.** Skill roots come from a `HOME` set to a temp folder, and
  re-ranker tests pass `secrets.NoKeychain()` or a fake keychain.

## Review Focus

1. **A stale or changed intent never passes as current.** `status`, `intent show`, `call` and `finish`
   all go through `oah.intent.explain_binding` with the lease's worktree as root. → Task 2
   `test_status_reports_each_binding_state`, Task 5 `test_call_refuses_stale_and_missing_binding`.
2. **Rebinding only moves forward.** The same ID with a higher revision rebinds. A lower revision, an
   in-place edit of the bound revision or a different ID refuses. → Task 1 `test_rebind_rules`.
3. **The bound packet is exempt from finish's scope check only while its binding is current.** Finish
   refuses a stale binding first (`OAH_INTENT_NOT_CURRENT`), so an edited goal cannot slip through as an
   exempt file. → Task 3 `test_finish_exempts_only_the_current_bound_packet`.
4. **Re-ranking can reorder but never drop.** → Task 6 `test_rerank_keeps_every_required_skill`,
   `test_rerank_dropping_provider_falls_back_to_rule_order`.
5. **The `[skills]` seam:** a config with toolkit `pins` must not break selection, and the reverse. →
   Task 6 `test_settings_accept_toolkit_and_selector_keys`.
6. **Real seams, not fakes.** Every success condition has one end-to-end test with real modules →
   Task 10.

### Task 2: `oah start --packet` and `oah status`

**Files:** Modify `src/oah/lease_cli.py`, `src/oah/intent_cli.py`; test `tests/test_intent_wiring.py`.

**Interfaces:**
- `oah start --task T --agent A --packet PATH [--scope …]`. `--scope` is required only without
  `--packet`. The packet is checked with `packet.check(path, task=T)`:
  - a draft refuses with `OAH_INTENT_NOT_ACCEPTED`, a different `Intent-ID` with
    `OAH_INTENT_ID_CHANGED`, and any other error with its own code;
  - an empty Scope refuses with `OAH_SCOPE_EMPTY` unless `--scope repo` is given;
  - the scope is the packet's Scope plus any `--scope`;
  - a packet outside the repository refuses with `OAH_INTENT_SOURCE_INVALID`.
- When the task already has your lease, `start --packet` rebinds through `Store.rebind` and prints
  `OAH_INTENT_REBOUND`, or `OAH_INTENT_UNCHANGED`. Otherwise it prints `OAH_LEASE_STARTED … intent=<id>@r<n>`.
- `oah status` adds `intent=<state>` to each line; `--json` adds `intent_state` and `intent_reason`.
- `oah intent show|check` judge the binding against the lease's worktree.

- [ ] Failing tests: `test_start_packet_binds_in_the_same_command`, `test_start_packet_refuses_draft`,

### Task 3: `oah finish --return`

**Files:** Modify `src/oah/lease_cli.py`; test `tests/test_intent_wiring.py`.

**Interfaces:**
- `oah finish … [--return FILE|-]`. Without a binding, nothing changes.
- With a binding:
  - a binding that is not `current` refuses with `OAH_INTENT_NOT_CURRENT`;

### Task 5: `oah call` refuses a stale binding and briefs carry the skills

**Files:** Modify `src/oah/call.py`, `src/oah/call_cli.py`, `src/oah/briefs.py`; test `tests/test_call.py`.

**Interfaces:**
- `call.lease_binding(state_dir, task) -> tuple[Binding | None, Path | None]`.
- `prepare` (before any engine is resolved): a bound task whose state is not `current` refuses with
  `OAH_INTENT_NOT_CURRENT`. A packet whose source differs from the lease binding refuses with
  `OAH_INTENT_SOURCE_MISMATCH`. Without `--packet`, the lease binding's source is the default packet.
- `CallRequest.no_rerank: bool = False`, plus `oah call --no-rerank`. A packet whose Constraints turn
  the re-ranker off has the same effect (`packet.rerank_disabled`).
- `call.plan_skills(root, *, state_dir, env, kind, stage, risk, scope, brief_disabled, keychain=None)
  -> SkillPlan(selection, rerank)`. The home folder comes from `env` (`HOME`, else `USERPROFILE`).
- `briefs.build(..., skills_block: str | None = None)`: when it is given, it replaces the one-line
  `- Skills:` bullet inside the preamble. The layout of C2 is unchanged.
- The run record adds `skills` (id, origin, digest, reasons) and `skills_rerank`.

**Interfaces:**
- `packet.render(task, *, plan=None, scope=())` and `packet.create(root, task, *, plan=None, scope=())`.

  (`rerank.advise_difficulty`, root = repository), selects and re-ranks skills per stage, and refreshes
  impact first (`preflight.refresh_impact`).

  off for the re-ranker.
