# Lane mdl: Model and Effort Judged per Call Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan
> task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** For every engine call, choose the model and the effort for that call's difficulty. When the
re-ranker is enabled with a key, one Jev request picks a (model, effort) pair from a closed candidate
set. oah's rules validate the answer and keep the deterministic choice whenever it is invalid,
unsupported or unavailable (amendment 6, intent `mdl` r1).

**Architecture:**
- **Deterministic choice** stays A14 + A1 (`models.map_tier`, then the adapter's effort resolution).
- **Candidates** come from one classifier, `models.CandidateSet.reject_reason(model, effort)`. The
  candidate list is every listed pair it accepts, so validation and candidate building cannot drift.
- **Judgement** goes through the existing re-ranker gate (`rerank._gate`, `_call`) and one new
  provider method (`choose_model`). The TypeSafe provider adds `build_model_request` and
  `parse_model_response` beside `build_advice_request`.
- **Wiring** is in `call.prepare`, so `oah call`, `oah fix` (which calls `call.prepare`) and the Orca
  launcher (which rebuilds argv from the prepared model and effort) all get the same choice and record.
- **Effective model** is checked in `call._effort_fields` beside the effort check, so direct launches
  and the Orca runner (`call.execute`) refuse a different header model alike.

**Tech Stack:** Python 3.11+ stdlib, `unittest`, the fake Codex/Claude CLIs under `tests/fakes`, a
fake re-ranker provider and the loopback TypeSafe server from `tests/test_rerank.py`.

**Spec:** `docs/PLAN.md` 5.5, 5.6, A1, A9, A10, A14, A17; amendment 6 (intent in the lane brief).

## Global Constraints

- Everything in the earlier plans still applies: stdlib only, never `shell=True`, UTF-8 everywhere,
  a Korean one-line header on new `.py` files, tests never reach the network.
- **No ranking is shipped.** Defaults name no real model; `quality_order` stays user configuration.
  Without a usable ranking, the listed models in `allowed_models` are unranked peers (Revision 2, Task 7);
  with neither, only the effort is judged, the model stays deterministic and the record says why.
- **Precedence.** A tier model pin, `--tier` and a packet `## Plan` tier are pins: the judge does not
  run and records `model_judge=unused(pinned)`. The judge never changes the engine or stage.
- **Closed candidates.** Listed (never hidden) catalog models ∩ `allowed_models` (empty = all), each
  with its supported ordinary efforts (`effort.ORDINARY`; behaviour-changing levels such as `ultra`
  are never candidates), each effort ≤ the model's `effort_caps` entry. With a ranking, no model weaker
  than the floor tier's deterministic model; always, no effort below the floor tier's effort. The floor
  tier is the routing kind floor (`routing.floor_tier(kind)`).
- **Caps bound the judge only.** The deterministic choice is never lowered by a cap (A1: never lower
  an effort silently).
- **Data sent** (AC3): stage, tier, the four axes and the candidate (model, effort) names. No code,
  brief text, task text or paths.
- **Record** (AC5): `result.json` gains `model_judge` (status), `model_choice` (deterministic, floor,
  candidates, proposal, provider, requested) and `header_model` (Codex header; `unverified` for
  Claude, whose aliases cannot be compared with `modelUsage` names). `resolved_model` and
  `launch_effort` stay what is passed to `-m` and the effort flag.
- **Refusal:** a Codex header model different from the requested model fails the run with
  `OAH_MODEL_MISMATCH` (`header_code`), like `OAH_EFFORT_MISMATCH`.
- **Scope note:** `src/oah/runs.py` joined the lease (renewed) because `RESULT_FIELDS` is the closed
  record vocabulary; the change only adds three field names.

## Review Focus

1. **The judge answers a pair outside the candidates, below the floor, above a cap or with an
   unsupported effort.** The call runs the deterministic pair and records `rejected(<rule>)`.
   → `test_model_judge.JudgeCallTest.test_rejected_answers_keep_the_deterministic_choice`.
2. **A pin is never overridden** (config tier model, `--tier`, packet Plan tier).
   → `JudgeCallTest.test_pins_are_never_judged`.
3. **Service errors, timeouts, malformed answers, no key, disabled** keep the deterministic choice and
   record `unused(<reason>)`. → `JudgeCallTest.test_unused_cases_keep_the_deterministic_choice`.
4. **Hidden models never become candidates; an empty `quality_order` never invents a ranking.**
   → `test_models.CandidateTableTest.test_candidate_table`.
5. **End to end:** the fake Codex receives the judged `-m` and effort, and a different header model
   refuses with `OAH_MODEL_MISMATCH`, on direct launches and through the Orca runner path.
   → `JudgeEndToEndTest.test_fake_codex_receives_the_judged_pair`,
   `test_header_model_mismatch_refuses`.
