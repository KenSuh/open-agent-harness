# P3s Skill Selection, Re-ranker and Key Lookup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Three pure library modules that later lanes call:
- `oah.skillsel` picks the installed skills a brief needs, with a reason for each;
- `oah.rerank` is the consent- and key-gated re-ranker interface, with TypeSafe Jev as its first provider;
- `oah.secrets` is the one documented way to read a key at runtime.

**Architecture:**
- **No command module.** This lane ships no `*_cli.py`. Callers (P3b briefs, P4b `packet new`, P7i impact)
  read their config section with `load_config(root).section("skills"|"rerank", DEFAULTS)` and pass the
  merged dict in. For P3b's `advise_difficulty(axes, task, root=root)` seam, omitted config loads the
  resolved launch target's `[rerank]` section with the same defaults, never the invoking directory's.
  Without either config or root, difficulty advice uses disabled defaults.
- **Skill selection** reads `SKILL.md` frontmatter from the roots it is given, read-only, every call.
  Rules are data (`DEFAULTS["rules"]`). Telemetry is an optional local JSON-lines append.
- **Re-ranker** is a gate (brief → enabled → provider → key) in front of a provider object. A provider
  may only return scores or advice; `oah.rerank` builds the order itself, so a provider can never drop
  a row.
- **TypeSafe adapter** isolates the request format in `build_*`/`parse_*` functions in
  `oah/rerank/typesafe.py`, following the public API reference (`POST /v1/systemone`, Bearer auth,
  Noul and Choice questions, read 2026-10-23 from docs.typesafe.ai `api/system-one.md` and
  `api/errors.md`).
- **Key lookup** is environment first, then the OS keychain through a small backend object, so tests
  inject a fake keychain or a fake `security` tool on a private search path.

**Tech Stack:** Python 3.11+ stdlib (`urllib.request`, `http.server` for tests, `ctypes` on Windows,
`hashlib`, `unittest`), external tools through `oah.engines.proc`.

**Spec:** `docs/PLAN.md` (3, 4 rows 30–31, 5.3, 5.5, 5.6, 5.10, 8, 15: A2, A4, A9, A10, A15, A17, C6)

## Global Constraints

- Everything from the P1, P2 and P3a plans' Global Constraints still applies: stdlib only, never
  `shell=True`, UTF-8 everywhere, CRLF-tolerant parsers, a Korean one-line header on new `.py` files,
  test writes inside the checkout.
- **Read-only selection.** `skillsel` never writes inside a skill root. It follows folder aliases,
  skips a `SKILL.md` over 1 MiB or not valid UTF-8, and records why.
- **No silent empty selection (A4).** An empty Scope adds `OAH_SCOPE_EMPTY` to the warnings, and
  selection by kind, stage and risk still runs. A selection with no skills says so in its text.
- **C6.** The brief text names the kind, stage, risk and availability behind each skill, and never says
  that no other skill may be used.
- **Gating order and strings** (shared with P7i):
  1. `unused(disabled-by-brief)`: the brief or `--no-rerank` turned it off;
  2. `unused(not-enabled)`: `[rerank] enabled` is false (the default);
  3. `unused(not-configured)`: no `provider` is set; `unused(unknown-provider)` for a name with no
     provider;
  4. `unused(no key)`: `oah.secrets.get` found no key;
  5. `used`, or `unused(error:<code>)` when the provider failed.
  A key alone never enables a provider.
  Difficulty advice with omitted config reports a disabled re-ranker as `unused(not-configured)`
  for P3b; explicit config retains `unused(not-enabled)`.
- **A provider never removes or lowers.** `rerank` returns a permutation of its input. Scores that are
  missing, duplicated or not finite make the whole result `unused(error:bad-response)` in input order.
  `advise_difficulty` records the AI tier next to the rule tier; `Advice.tier` is always the rule tier.
- **Data sent (TypeSafe).** Re-rank: the task kind, the caller's query, and each candidate's name and
  description, each description cut to 200 characters. Advice: the four axes and the task summary, cut
  to 500 characters. Nothing else, and never paths the caller did not put in a name.
- **Transport.** `urllib.request` with the configured timeout (default 10 s). The URL must be
  `https://`, or `http://` on a loopback host (tests). Automatic proxies and redirects are disabled
  to keep credentials at that endpoint. No retries: the re-ranker is advisory.
- **Keys (A17).** A key appears only in the `Authorization` header. It never reaches a result record,
  telemetry, an exception message or any `repr`. Keys travel as opaque `Secret` objects with redacted
  `str`/`repr`; formatting and pickling are refused. Only the innermost transport calls `reveal()` and
  deletes the revealed string in `finally`. Public wrappers drop the environment/keychain references
  before transport and clear their call closures on exit. Provider and transport errors use fixed
  messages and codes, raised outside exception handlers so `__context__` and `__cause__` are None.
  No exception retains response bytes or text. Sensitive helpers return a value, a code-only failure
  or a sanitized interruption before public entry points delete their inputs and raise a fresh error
  with `.with_traceback(None)`.
  Interruptions (KeyboardInterrupt, SystemExit and GeneratorExit, including multiple-inheritance
  subclasses) always propagate as fresh, unchained exceptions. Provider calls (including key-name
  lookup and name access) and public result validation run within a classified boundary; TypeSafe
  wrappers use the same failure classifier, in this fixed order:
  any direct or grouped interruption; any remaining BaseExceptionGroup → internal; ProviderError with
  a valid plain-string code in its instance dictionary → that code; everything else → internal.
  Group inheritance never permits a provider-code lookup. Built-in descriptors and dictionary
  iteration bypass properties, attribute hooks, dictionary hooks and untrusted string/key methods.
  Public result validation accepts only exact built-in types: list/tuple score containers, a tuple
  advice pair, string tiers and provider/key names, and finite int/float numbers (never bool).
  Subclasses and other values become `bad-response` through that classifier without invoking their
  conversion, iteration, indexing, attribute or equality hooks. Both public APIs consume classified
  codes from calls and validation instead of rethrowing an original error; validated provider codes
  retain their precedence over ordinary parse errors when a call or validation raises a hybrid.
  Classification failures become internal unless they contain an interruption; cleanup cannot
  replace an interruption already selected. No original exception, chain or private frame survives.
  An iterative depth-first scan selects
  the first interruption in a group, visiting shared subgroups only once; groups are never rebuilt.
  The base allocator preserves the selected type without arguments or subclass constructors when
  possible; otherwise the fallback allocates only its plain built-in interruption base. No original
  notes, attributes or tracebacks survive, and cleanup failures never replace an interruption with
  a provider error. A group without interruptions becomes a fixed internal provider error.
  Tests generate fake keys with `secrets.token_hex` and inspect the whole exception chain,
  attributes, arguments, all package-owned frame locals (including public wrappers and closures) and
  `capture_locals=True` traceback formatting
  for every failure path; fixture and caller frames are excluded because they supply the key.
  The exception matrix injects failures during score and confidence validation through both public
  APIs, including hybrids and private chains, and verifies that result-subclass hooks never run.

## Interfaces

### `oah.secrets`
- `SERVICE = "oah"`; `NAME_RE = [A-Za-z_][A-Za-z0-9_]{0,63}`.
- `Secret(value)`: redacted `str`/`repr`, no formatting or pickling; `reveal() -> str` is transport-only.
- `get(name, *, env=None, keychain=None) -> Secret | None`: wraps `env[name]` when non-empty, else
  `keychain.lookup(name)`, else None. An invalid name raises `ValueError` (a programming error).
- `system_keychain() -> Keychain`: `MacKeychain()` on macOS, `WindowsCredentials()` on Windows,
  otherwise `NoKeychain()`.
- `MacKeychain(search_path=None, timeout=10.0).lookup(name)`: runs the macOS `security` tool with
  `find-generic-password -s oah -a <name> -w`; exit 0 → stdout without its final newline; anything
  else (not found, timeout, tool missing) → None.
- `WindowsCredentials().lookup(name)`: `CredReadW("oah:<name>", CRED_TYPE_GENERIC)`; the blob is
  decoded by `decode_blob` using UTF-16-LE, as written by `cmdkey`, without encoding guesses;
  other encodings are unsupported. `CredFree` always.
- `decode_blob(data: bytes) -> str | None` is portable and tested everywhere.

### `oah.rerank`
- `DEFAULTS = {"enabled": False, "provider": "", "timeout_seconds": 10.0, "max_candidates": 50,
  "typesafe": {"url": ..., "model": "jev-latest", "key_name": "TYPESAFE_API_KEY"}}`.
- `Candidate(name: str, description: str = "")`, frozen; names must be unique per call.
- `RerankResult(order, status, provider, scores)`; `.used`; `.to_record() -> dict`.
- `Advice(rule_tier, advisory_tier, confidence, status, provider)`; `.tier` is `rule_tier`;
  `.to_record()`.
- `rerank(kind, candidates, *, config, query="", brief_disabled=False, env=None, keychain=None,
  providers=None) -> RerankResult`.
- `advise_difficulty(axes, task, *, config=None, root=None, brief_disabled=False, env=None, keychain=None,
  providers=None) -> Advice`. `axes` is a `routing.Axes` (rule tier from `routing.recommend`) or a
  mapping holding `kind`, `intensity`, `reasoning`, `risk` and the rule `tier`.
- `ProviderError(code)`; `Provider` protocol: `name`, `key_name(config)`,
  `score(kind, query, candidates, *, key: Secret, config) -> dict[str, float]`,
  `advise(axes, task, *, key: Secret, config) -> tuple[str, float | None]`.
- `PROVIDERS = {"typesafe": TypeSafeProvider()}`.

### `oah.rerank.typesafe`
- `build_rerank_request(model, kind, query, candidates) -> dict`: one Noul question per candidate
  (`c0`, `c1`, …) over one shared state, so a single request scores the whole list.
- `parse_rerank_response(body, count) -> list[float]`.
- `build_advice_request(model, axes, task) -> dict`: one Choice question over `low|medium|high|max`.
- `parse_advice_response(body) -> tuple[str, float]`.
- `post_json(url, payload, *, key: Secret, timeout) -> dict`; HTTP status → `ProviderError` codes
  `unauthorized` (401), `rate-limited` (429), `overloaded` (529), `http-<n>`, plus `timeout`,
  `network`, `insecure-url`, `bad-response`, `invalid-header` (credentials must be visible ASCII).

### `oah.skillsel`
- `DEFAULTS = {"mode": "reference", "telemetry": True, "attach_max_bytes": 65536, "exclude": [],
  "file_kinds": {".py": "python", …}, "rules": [ {skill: [names…], kinds, stages, risks, file_kinds,
  reason}, … ]}`. An empty list in a rule means "any".
- `SkillRoot(path, origin, label, plugin="")`; origins in precedence order (A15): `project`, `kit`,
  `user`, `plugin`.
- `default_roots(repo_root, *, home, env, kit_cache=None) -> list[SkillRoot]`: project
  `.claude/skills` and `.agents/skills`, the kit cache, user `~/.claude/skills` (or
  `$CLAUDE_CONFIG_DIR/skills`), `$CODEX_HOME/skills` (default `~/.codex/skills`), `~/.agents/skills`,
  and each user-scope plugin's `skills/` from `plugins/installed_plugins.json`.
- `installed(roots) -> InstalledSet`: every skill with id, name, description, path, origin, digest;
  the highest-precedence copy wins per id, the rest are listed as shadowed.
- `file_kinds(scope_paths, table) -> tuple[str, ...]`.
- `select(kind, stage, risk, scope_paths, *, roots, settings=DEFAULTS, state_dir=None, now=None)
  -> Selection`. When `state_dir` is given and `settings["telemetry"]` is true, the selection is appended
  to `<state_dir>/skills-telemetry.jsonl` under the state lock.
- `Selection(kind, stage, risk, scope_count, file_kinds, mode, skills, unavailable, warnings)`;
  `.brief_text() -> str`; `.to_record() -> dict`.
- `SelectedSkill(id, name, path, label, origin, digest, reasons, text)`; `text` is set only in attach
  mode.

## Review Focus

- A provider result can never drop, duplicate or invent a candidate; the gate order is exact.
- No key text in records, telemetry, exceptions or `repr` (prove it with the fake server).
- Selection never writes into a skill root, re-reads every call, and is never silently empty.
- The Windows credential path: structure layout, `CredFree`, error 1168 → None.
