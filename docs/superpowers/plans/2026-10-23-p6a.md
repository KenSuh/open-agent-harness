# P6a Review Loop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `oah review --task T [--base REV]` runs one review round of the task's committed head against its
base in a sanitized read-only snapshot, validates the reviewer's output, writes an immutable receipt and
says whether the series converged, needs another round or needs a decision.

**Architecture:**
- **One round per invocation.** The command resolves base and head, takes a per-series lock, refreshes the
  impact map (A11), validates the stored history, builds a sanitized snapshot with a canary, dispatches
  Codex through `oah.call` (stage `review`, read-only, a dispatched worker) and validates what it returns.
  A validated finished round writes `reviews/<task>/R<n>.json` even when effort is unverified, as
  PLAN 5.5 requires; it records `effort_verified: false` and the normalization basis. A mismatch or
  downgrade fails without counting; other failed or invalid calls also spend the per-round attempt budget.
- **History is append-only records.** Receipts and correction attempts are immutable files under
  `<state>/reviews/<task>/`, each indexed with its digest in `index.jsonl`. Decisions about the series
  (converged, another round, decision stop, budgets) are derived from those records and a round-attempt log;
  nothing is recovered automatically.
- **Codex only, for now.** The review stage must be `codex`; any other engine refuses with
  `OAH_REVIEW_ENGINE_UNSUPPORTED` (structured output, `--ephemeral` and ignored user config are Codex flags).

**Tech Stack:** Python 3.11+ stdlib (`subprocess` through `oah.engines.proc`, `secrets`, `hashlib`, `json`,
`tempfile`, `unittest`), git, fake engines.

**Spec:** `docs/PLAN.md` 5.9 (steps 1–8, `independent`), 5.6 (returns), 5.10 (A11 refresh), 3, 5.3, 8,
section 4 row 22, A1, A3, A6, A7, A11, A22, A23 and the P6 checklists of section 15, except `oah fix`,
`oah review summary` and `oah land` (lanes P6b, P6c). The lane brief's intent (p6a r1) is authoritative.

## Global Constraints

- Python 3.11+, stdlib only; never `shell=True`; prompts on stdin; UTF-8 on every read and write; parsers
  accept CRLF; executables resolve through `oah.engines.proc`; a one-line Korean header on new `.py` files.
- Settings are parameters. `[review]` lives in `oah.review.settings.DEFAULTS` (lanes P6b/P6c extend that dict):
  `max_rounds` (unset = no ceiling), `round_attempts = 2`, `codex_sha256 = ""` (unset), `critical_paths`
  (`.github/workflows/**`, the agent instruction files at any depth, `**/migrations/**`, `.oah/config.toml`).
- **The reviewed change never configures its own review.** `[stages]`, `[engines]`, `[models]` and `[review]`
  are read from `.oah/config.toml` as committed at the base (`oah.config.parse_config` reads a commit's bytes).
  The default branch comes from the worktree's `[preflight] remote` and `default_branch` (a plain branch name);
  when the change edits those, the base must be given with `--base`. `[impact]` stays the worktree's (the
  persisted map binds it).
- **State layout** (`<state>/reviews/<task>/`):
  - `R<n>.json` — receipts, numbered per task in creation order (a rebased task starts a new series but
    keeps numbering, so names never repeat). `round = n`; `series_round` is the position in the series.
  - `A<k>-start.json`, `A<k>-outcome.json`, `A<k>-head.json` — correction-attempt records (P6b writes them).
  - `index.jsonl` — one line per record, in publication order: `{kind, name, digest, recorded_at}` plus
    `round, base, head, verdict, outcome` for receipts. The index line is the commit point.
  - `rounds.jsonl` — the round-attempt log (start/finish of every dispatched attempt); not history.
  - `.locks/<base>.lock` and `.locks/task.lock` — the per-series lock and, because receipt numbers are per
    task, a task lock; both are held for the whole round (`StateLock`, timeout 0, `OAH_REVIEW_SERIES_BUSY`).
- **Records are immutable.** Publication writes the file with exclusive create, fsyncs it, then appends the
  index line under the state lock. A file without an index line, a digest mismatch or an unparsable index
  is invalid history (`OAH_REVIEW_NEEDS_DECISION`), never repaired automatically.
- **Digests** are `sha256:<hex>` of exact file bytes; records are written as sorted, indented JSON + LF.
  `history_digest` is the digest of the canonical JSON list of `{kind, name, digest}` supplied to the round;
  the first round supplies an explicitly empty list.
- **Correction-attempt format** (read here, written by P6b with `receipts.publish`, which refuses anything
  else; every record has exactly these fields plus an optional `run_id`; `schema: 1`, `kind`, `task`,
  `attempt_id` = `A<k>`):
  - start: `source_receipt`, `source_receipt_digest`, `finding_ids[]`, `class_ids[]` (each id once; the class
    ids are exactly the classes of those findings), `before_head`, `engine` (`claude|codex|human`), `manual`
    (bool), `started_at`;
  - outcome: `outcome` ∈ `applied | no-change | failed | aborted`, `after_head` (present; a full SHA only for
    `applied`, else null), `evidence` (non-empty), `finished_at`;
  - head binding (only after an `applied` outcome with a null `after_head`): `after_head`, `evidence`,
    `bound_at`.
  - The reader merges them into `{attempt_id, source_receipt_digest, finding_ids, class_ids, before_head,
    after_head, outcome, evidence}`. Malformed records, a missing start, an outcome before its start, unknown
    source receipts, ids not in the source receipt, an unfinished attempt, or an applied result without a new
    bound commit make the history invalid (no decision overrides that). A correction on the task's latest
    receipt that no longer descends from the reviewed head or is not in the reviewed history (amend, squash,
    rebase) is an ambiguity the user settles with `--decision`.
- **Task-wide memory.** Class definitions, attempted classes and every decision stop (counted or uncounted)
  are read across all series of the task. The complete task log determines pending uncounted stops and
  decisions; only round numbering and attempt budgets filter by base. A new base never clears a pending
  decision or a tried class; prior references stay within the series.
- **Codes** (first token of the message). Exit 0 only for `OAH_REVIEW_CONVERGED`; 1 for the other outcomes and
  refusals; 2 usage; 69 environment (config, git, storage, snapshot creation, a missing reviewer CLI).
  `OAH_REVIEW_CHANGES_REQUESTED`, `OAH_REVIEW_NEEDS_DECISION`, `OAH_REVIEW_ROUNDS_EXHAUSTED`,
  `OAH_REVIEW_ATTEMPTS_EXHAUSTED`, `OAH_REVIEW_DIRTY_TREE`, `OAH_REVIEW_SERIES_BUSY`, `OAH_REVIEW_BASE_INVALID`,
  `OAH_REVIEW_NOTHING_TO_REVIEW`, `OAH_REVIEW_ENGINE_UNSUPPORTED`, `OAH_REVIEW_BINARY_MISMATCH`,
  `OAH_REVIEW_CANARY_MISSING`, `OAH_REVIEW_CANARY_CONFLICT`, `OAH_REVIEW_OUTPUT_INVALID`,
  `OAH_REVIEW_ENGINE_FAILED`, `OAH_REVIEW_PROXY_CREDENTIALS`, `OAH_REVIEW_WORKER_REFUSED`, `OAH_REVIEW_DECISION_EMPTY`,
  `OAH_REVIEW_SNAPSHOT_FAILED`, `OAH_REVIEW_GIT_FAILED`, `OAH_REVIEW_RECORD_EXISTS`, plus the shared
  `OAH_INTENT_NOT_CURRENT`, `OAH_INTENT_RETURN_INVALID`, `OAH_EFFORT_DOWNGRADED`, `OAH_EFFORT_MISMATCH`,
  `OAH_IMPACT_STALE`, `OAH_WORKTREE_UNRESOLVED` (the lease's worktree is gone) and `OAH_ENGINE_MISSING`.
  Warnings: `OAH_REVIEW_DECISION_UNUSED`, `OAH_REVIEW_EXTRA_ROUND_UNUSED`, `OAH_REVIEW_SNAPSHOT_LEFT`.
- **Which tree.** `oah review --task T` reviews the worktree the task's lease names, from any worktree of the
  repository.

## Decision rules (one place: `oah.review.rounds`)

- **Blocking** findings are P0/P1. With no blocking finding the series ends: `approve` → converged; P2/P3
  findings become `follow_ups`, whatever their class.
- With blocking findings, the round stops with `OAH_REVIEW_NEEDS_DECISION` when any blocking finding is in an
  attempted class (any terminal outcome), or uses any class whose normalized mechanism and rule equal an
  attempted class's, or needs a `design` or `stored-format` fix, or lies outside the task scope. Otherwise it
  is `OAH_REVIEW_CHANGES_REQUESTED`. A reworded finding or one reported without prior references is judged
  by its class, never by its wording.
- A stop is sticky: the next invocation of the task refuses with `OAH_REVIEW_NEEDS_DECISION` until it is
  run with `--decision "<what you decided>"`, which is recorded in the round log, the events and the
  receipt. The decision settles the rest of its round, so a retry after an uncounted call needs no second
  decision, until a later call stops for a decision again. Pre-dispatch history problems are not
  overridable: the history must be repaired.
- Before dispatch: use `oah.call`'s dispatch-binding reader and lineage validator before checking cached
  approvals. Check task-wide waits next. Converged at this exact head and complete current intent binding
  (`source`, `id`, `revision`, `digest`) with no wait
  → exit 0, nothing launched. A decision clearing a wait runs and records a new round. After a receipt that requested
  changes, every P0/P1 finding of it needs a terminal correction-attempt record (5.9: manual corrections need
  the same records); missing ones stop with `OAH_REVIEW_NEEDS_DECISION` (recurrence evidence is missing),
  which `--decision` may override. `max_rounds` reached → `OAH_REVIEW_ROUNDS_EXHAUSTED` unless
  `--extra-round` (recorded); `round_attempts` dispatched attempts of this round already used →
  `OAH_REVIEW_ATTEMPTS_EXHAUSTED` unless `--extra-attempt` permits one additional call, recorded in the round
  log, events and receipt. It never raises the pinned base configuration or carries into a retry.
  One invocation makes at most one paid call.

## Review Focus

1. **A repository that tries to steer the reviewer** (instruction files at any depth or in any letter case,
   a tracked `.oah-review-canary`, prompt text in source). Expect stripping case-insensitively at every
   depth, `OAH_REVIEW_CANARY_CONFLICT` for a planted canary, and the untrusted-content statement.
   → Task 2 `test_strip_is_case_insensitive_at_every_depth`, `test_tracked_canary_refuses`.
2. **A crash between writing a receipt and indexing it.** Expect `OAH_REVIEW_NEEDS_DECISION` naming the
   unindexed file, not a silent repair. → Task 1 `test_unindexed_record_is_invalid_history`.
3. **A reviewer that re-mints a new class id for an attempted class.** Expect the normalized definition match
   to stop the series. → Task 5 `test_reminted_class_definition_of_attempted_class_stops`.
4. **The review loop re-run without any recorded fix** (an agent looping on `oah review`). Expect
   `OAH_REVIEW_NEEDS_DECISION` naming the uncorrected findings before any paid call. → Task 6
   `test_next_round_needs_correction_records`.
5. **A snapshot left behind after a failure** (engine crash, invalid output, KeyboardInterrupt).
   Expect removal on every path. → Task 2 `test_snapshot_removed_on_exception`, Task 6
   `test_snapshot_removed_after_failed_round`.
