# P7j Default-Branch Impact Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan
> task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** before a query, `oah impact` fetches the remote's default branch read-only and refreshes a
second persisted map for the fetched commit, next to the worktree map. The output names both maps by
commit SHA and merges their rows without duplicates, marking rows found only on the default branch.
Offline, disabled or failed fetches fall back to the last fetched ref, always labelled.

**Architecture:**
- **`oah.impact.defaultbranch`** (new, config-free): finds the remote and the default branch, runs the
  fetch, and returns a `DefaultBranch` result (state `fresh | stale | unavailable`, reason, remote,
  branch, commit, map info and data). It holds no lock while fetching.
- **`oah.impact.mapstore`** gains the ref map: `ref_map(root, ref, *, refresh, env, settings)` stores
  `<state>/impact/maps/<worktree key>.default-branch.json` beside the worktree map, under the same lock
  (`<state>/impact/.lock`). Its manifest is `worktree`, `ref`, `head` (the fetched SHA) and `tool`; its
  inputs are the `blob:<oid>` keys from `git ls-tree`. Freshness uses the same `_judge` and result
  digest; refresh uses the same `refresh_data`, generalised with `rev=` so it reads blobs at the commit.
  An incremental refresh equals `build_data(root, sha)` byte for byte.
- **`oah.impact.query.merge_maps`** merges the worktree rows with the default-branch rows. Two rows are
  the same when `(binding, layer, source, line, target)` match; the worktree row is kept. Each row is
  marked `both`, `worktree` or `default-branch`. The single re-ranker call site is unchanged and runs on
  the merged rows.
- **`impact_cli`** adds `--offline`, prints `maps: worktree=<sha> default-branch=<sha|stale(…)|
  unavailable(…)>` and a JSON `maps` object, and marks default-branch-only rows. Actions (`build`,
  `refresh`, `status`) and `ensure_fresh(root)` never fetch. Directory and task-Scope selections use
  the union of both maps' files, with the existing kind filters, before either map is queried.

**Tech Stack:** Python 3.11+ stdlib, git through `oah.paths.git_argv` and `oah.engines.proc.run_command`.

**Spec:** `docs/PLAN.md` 5.10 ("The latest default branch (A23)"), A23 in amendment 5, section 15 P7j;
lane intent p7j.

## Global Constraints

- Everything from the P1, P2 and P7i plans' Global Constraints still applies.
- **Remote:** the current branch's `branch.<name>.remote` when it names a configured remote, else
  `origin` when configured, else none (`unavailable(no remote)`).
- **Default branch:** `refs/remotes/<remote>/HEAD`; else, when the network may be used,
  `git ls-remote --symref <remote> HEAD`; else the ref in this worktree's persisted default-branch map
  for the selected remote; else `main`. Saved discovery metadata must have a valid manifest digest and
  matching worktree identity; it is also recovered when discovery fails or refresh is disabled.
- **The fetch (A17, AC4):**
  `git -c core.askPass= -c maintenance.auto=false -c gc.auto=0 -c remote.<r>.followRemoteHEAD=never -C <root> fetch
  --quiet --no-tags --no-recurse-submodules --no-write-fetch-head --no-prune --refmap= <r>
  +refs/heads/<b>:refs/remotes/<r>/<b>`. Command-line `-c` writes nothing. Only that one remote-tracking
  ref changes, even with additional configured fetch mappings to tracking refs or local branches;
  no `FETCH_HEAD`, no tags, no configuration. stdin is closed and the timeout is `[impact] git_timeout`.
  Both discovery and fetch set `GIT_TERMINAL_PROMPT=0`, `GCM_INTERACTIVE=never`, empty `GIT_ASKPASS` and
  `SSH_ASKPASS`, `core.askPass=`, and `SSH_ASKPASS_REQUIRE=never`. They force the OpenSSH variant with
  `ssh -oBatchMode=yes -oNumberOfPasswordPrompts=0 -oStrictHostKeyChecking=yes`, overriding interactive
  SSH commands and wrappers. OpenSSH host/key configuration and agents still apply; users of custom
  wrappers can configure OpenSSH or fetch manually and query with `--offline`. This A23 unattended
  behavior prevents login and host-key dialogs. Git handles credentials itself; oah reads, passes and
  stores none, and never prints git's stderr (it could hold a URL).
- **Labels (AC3):** `fresh` → `default-branch=<sha>`; otherwise `default-branch=stale(<reason>)` with
  `last-fetched=<sha>`, or `default-branch=unavailable(<reason>)` when no fetched ref exists. Reasons:
  `offline`, `refresh_default_branch=false`, `no-refresh`, `no remote`, `fetch failed`,
  `fetch timed out`, `default branch lookup failed`. Stale and unavailable also print an
  `OAH_IMPACT_DEFAULT_BRANCH_STALE` / `OAH_IMPACT_DEFAULT_BRANCH_UNAVAILABLE` warning on stderr that says
  what to do. The query never fails because of the network.
- **`--no-refresh`** fetches nothing and builds nothing: a stored default-branch map that matches the
  current tracking ref is used as `stale(no-refresh)`, otherwise `unavailable(no-refresh)`.
- **DB entities:** an entity unknown to the default-branch map is skipped there (it is new in the lane);
  one unknown to the worktree but known on the default branch is answered from it. Only when neither map
  knows it does the query refuse as before. When the default branch has a DB graph, JSON `db_impact.maps`
  names each available graph by `worktree` or `default_branch`, with its own `commit` and `graph` digest.
  `merged_output` hashes the printed DB rows, including `found_in`; text prints the same map identities
  and `merged-output`. This A23 output change prevents attributing combined rows to one commit. Without
  a default-branch DB graph, P7i's existing `commit`, `graph` and `output` format remains unchanged.
- **Coverage warnings:** default-map symlink exclusions and unparsed SQL warnings reach stderr and the
  top-level JSON `warnings`, labelled with the source map and its commit. Worktree warnings keep P7i's
  format. This A23 addition makes missing coverage visible even when the fetched map is fresh.
- The gate layer stays as P7i left it (`gatebind.discover` reports unavailable), and gates are queried
  once, from the worktree. Rows newly bound on the default branch come from the lexical layers (workflow,
  manifest and config commands give pin and exec).

## Review Focus

- The fetch writes nothing but `refs/remotes/<r>/<b>` and objects: no config, no `FETCH_HEAD`, no tags,
  no other ref; no credential helper runs for a local remote.
- `--offline`, `refresh_default_branch = false` and `--no-refresh` start no `git fetch` and no
  `git ls-remote` (checked with `GIT_TRACE`).
- An old ref is never used without the `stale(...)` label; a missing ref never hides the worktree answer.
- Ref-map incremental refresh equals a full build at the fetched SHA.
- Merging never drops a pin or exec row and never prints the same row twice.

## Tasks

### Task 1: Setting — `oah.impact.defaults`

- `DEFAULTS["refresh_default_branch"] = True`; `_check` requires a bool
  (`OAH_CONFIG_INVALID` otherwise). It is not in `MAP_KEYS`.
- Tests: `test_refresh_setting_default_and_type`.

### Task 2: Ref map — `oah.impact.mapstore`

- `refresh_data(root, old, old_inputs, inputs, head, settings, *, rev=None)` — with `rev`, scans and
  the DB graph read blobs at `rev` and history starts at `rev`.
- `tree_inputs(root, sha, settings) -> (inputs, excluded)` — `blob:<oid>` per tracked blob at `sha`.
- `ref_map_path(state, root)`; `ref_map(root, ref, *, refresh=True, env=None, settings=None)
  -> (MapInfo, data)`; with `refresh=False` it returns the stored map only when it matches, else raises
  `OAH_IMPACT_STALE`.
- Tests: `test_ref_map_persisted_beside_worktree_map`, `test_ref_map_incremental_equals_full`,
  `test_ref_map_fresh_is_reused`.

### Task 3: Fetch and labels — `oah.impact.defaultbranch`

- `remote_for(root, timeout) -> str | None`, `default_branch_name(root, remote, *, network, timeout)
  -> (branch, reason)`, `fetch(root, remote, branch, timeout) -> str | None` (reason on failure),
  `refresh(root, settings, *, offline=False, no_refresh=False, env=None) -> DefaultBranch`.
- `DefaultBranch.label()`, `.commit`, `.to_json()`, `.warning()`.
- Tests: `test_upstream_remote_preferred`, `test_ls_remote_finds_default_branch`,
  `test_fetch_timeout_is_stale`, `test_fetch_is_read_only`, `test_fetch_ignores_configured_refmaps`,
  `test_discovery_and_fetch_disable_askpass`, `test_discovery_and_fetch_force_noninteractive_ssh`,
  `test_windows_batch_askpass_is_disabled`, `test_discovered_trunk_survives_failed_fetch`,
  `test_saved_trunk_survives_skipped_or_failed_discovery`.

### Task 4: Merge — `oah.impact.query.merge_maps`

- `merge_maps(worktree, default_branch) -> (rows, found_in)`; `found_in[row]` is `both`, `worktree` or
  `default-branch`.
- Tests: `test_merge_maps_dedupes_and_marks`.

### Task 5: CLI — `oah.impact_cli`

- `--offline`; query flow: worktree map, then `defaultbranch.refresh`, then rows from both maps,
  `merge_maps`, `apply_rerank`, `cap`. Text: `maps: …` after `map: …`, default-only rows end with
  `[default-branch only]`. JSON: `maps`, `label`, and `found_in` on each row.
- Tests (real processes, local bare remotes): `test_two_maps_show_new_default_branch_check`,
  `test_unreachable_remote_is_stale`, `test_offline_runs_no_fetch`, `test_refresh_off_runs_no_fetch`,
  `test_no_refresh_runs_no_fetch`, `test_no_remote_is_unavailable`, `test_never_fetched_is_unavailable`,
  `test_db_entity_new_in_lane`, `test_ensure_fresh_never_fetches`,
  `test_directory_and_task_scope_include_default_branch_files`, `test_default_branch_coverage_warnings_are_visible`,
  `test_default_branch_only_db_identity`, `test_merged_db_identity_names_both_maps`.
